Project: MedMap — a hospital-placement recommendation tool for TigerHacks26.

CONTEXT
MedMap recommends where a new hospital should be built to reduce driving
distance and lift burden off existing hospitals, using census/population
data, HRSA shortage-area designations (MUA/HPSA), and existing hospital
locations. There is a MapLibre GL JS frontend already started, and the
raw data lives in CSV files (schema not yet documented on my end).
